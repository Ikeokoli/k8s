# Cluster Rollout Console

A self-contained React operations console for reviewing Kubernetes-style service rollouts, filtering environments, and making an approval decision without external credentials.

## Requirements

- Node.js 20
- pnpm 10

## Commands

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm lint
pnpm typecheck
pnpm build
```

All application data is local and deterministic.
